# 0.6.12 安装组合与组件来源

本版使用统一 Python 发行版本与三平台默认清单。Linux 原生组件仍来自已验证的 v0.6.10 资产，Windows 来自已验证的 v0.6.11 P36 资产，macOS 使用固定 P35 原生构建及 macOS26 复测。清单保留原始资产 URL、文件名、完整文件哈希、工具链和目标配方 ID，不要求为更新 Python 版本号重新编译 Rust。

新版本只修改发行版本字段；31 个运行时行为模块与此前已验证的代码逐字节一致。Native runtime、协议机制与模型生成代码的正确性仍分别记录。

正常安装使用 `python install.py --root <全新验证目录> --no-activate`。不提供原生 manifest 或 archive 覆盖参数，验证默认平台选择及实际下载。既有安装保持可用，活动 home 和不可变入口不被替换。安装成功后，先回读当前版本、模块来源和正常 app-server/EOF，再按既有升级步骤切换。

候选与稳定状态以[本版索引](../reports/releases/0.6.12/README.md)和公开发布回执为准。未完成的模型业务基准、未知云消费记录、其他 App 版本及 CADSG GUI 不因统一版本号自动获得资格。

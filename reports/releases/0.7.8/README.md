# CDS 0.7.8 网页 MCP 配置维护候选

Windows 的真实 0.7.7 隔离冷续接中，启动器按设计更新独立 home 的内置网页 MCP 解释器路径，但写回时把原有 LF 配置全部改成 CRLF。该测试 home 随后依据事前 SHA-256 精确恢复原始字节，并核验所有者与 DACL；原始变化和恢复记录保留。

此前读取使用通用换行，写入依赖平台默认换行。候选保留原始换行读取，并以不隐式转换的方式写入；纯 CRLF 原文件中新生成的行保持 CRLF，混合换行的既有行不全局归一化。命令不变时仍不重写；未知用户自有 MCP stanza 仍明确拒绝。

实际 Windows 旧版对 LF 和混合换行的定向反例失败，候选在 Windows 对应反例通过；macOS 另验证 LF、CRLF、混合换行、幂等及既有浏览器合同。各平台最终安装与发布状态以对应 Release 附件为准。此修复不代表 CADSG App 的冷历史选择或 Part Two 40 秒问题已解决。

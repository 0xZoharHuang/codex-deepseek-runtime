# 0.6.12 三平台候选组合

本组合用于补齐 macOS 交付并统一安装入口。现阶段仍为候选，新的正常安装与公开交付核验尚未完成；Linux v0.6.10、Windows v0.6.11 的稳定交付继续保留。

31 个运行时行为模块与 Windows v0.6.11 完全一致，只更新发行版本字段。原生 Codex 工具、审批、沙箱、会话和子智能体继续由同一固定上游运行时实现，没有重新编译原生程序。

- Linux 复用 v0.6.10 的已验证不可变归档及公开 URL。
- Windows 复用 v0.6.11 的 P36 已验证不可变归档及公开 URL。
- macOS 使用原 macOS15 编译产物，在 macOS26 上通过当前原生与完整离线复测；本次提供正常安装清单和公开归档。

原生归档的组件版本可以早于 Python 发行版本。清单明确记录实际 URL、文件名、原生配方 ID、工具链和完整文件哈希，不把复用归档写成新编译。安装器仍须核对这些内容。

新的安装资格通过 `installed-release-qualification.yml` 验证默认 manifest/公开 URL、正常独立安装、实际模块来源、正常入口握手/EOF/provider 退出，并执行当前原生传输与完整离线测试。原生产 Python 环境不安装 QA 依赖，测试使用独立环境。模型推理与真实凭据读取不属于这个安装检查。

完整范围见 [机器可读索引](qualification-index.json)。既有 Windows Jinja 业务基准失败、上游不确定消费记录及其保护 pin 仍保留，不因新版本号改成通过。CADSG / Codex App 继续单独验收。

# 0.6.12：Linux / macOS 独立发行

**Linux/macOS 已正式发布。** [公开交付回执](publication-receipt.json)记录实际资产、源码和 Windows 下载读回。

本版完成各自默认公开 URL 的全新正常安装、32 个安装模块来源核验、实际入口握手与自然退出，并在各自系统执行当前原生传输/恢复和完整离线检查。CI 源码为 `b9bc76fbc27150cb78b84816f69f8b32f883dfb3`；最终 tag 只增加本报告和安装文档，不改变产品代码、配方或清单。

| 平台 | 本版实际验证 |
| --- | --- |
| Linux Ubuntu 24.04 x64 | 正常安装；原生 22/22；离线 2828 通过、55 项平台条件跳过、0 失败。 |
| macOS 26.6.2 arm64 | 正常安装；原生 22/22；离线 2827 通过、56 项平台条件跳过、0 失败。 |
| Windows x64 | 正常安装和入口检查通过；仍复用 v0.6.11 P36。新确认的私有祖先目录 Node 属性句柄问题未修复，不列为本次平台完成。 |

原始 CI ZIP、逐项断言、跳过原因和安装进程回执保存在 [ci](ci/)；[机器索引](qualification-index.json)绑定 ZIP SHA、源码、完整收集和原生归档。这一轮零模型请求，验证安装与机制；真实模型任务沿用明确列出的既有版本证据，不冒称重新执行所有业务 benchmark。

31 个运行时行为模块与 Windows v0.6.11 相同，仅发行版本字段改变。Linux 复用 v0.6.10 原归档，macOS 使用固定 P35 组件；安装器核对实际 URL、完整文件、SHA、配方与工具链。没有为版本号重新编译 Rust。

Windows 私有盘符顶层目录的 Node `EPERM lstat` 已在项目隔离目录复现。只读取属性的 ACL 不满足实际句柄；补齐同步位的对照组可执行普通 `.js` 文件，同时仍拒绝目录枚举、写入与私有旁文件。对照实验不是已发布修复，不能要求下游用 stdin 绕过。原 Git 标准子目录布局已由下游正常工具执行和同线程冷恢复核回。

原 Windows Jinja 业务基准失败、不确定云消费保护 pin、原始超时与 macOS 旧 CI 失败继续保留。OpenAI 云权益、模型质量和 CADSG App GUI 不因本版 CLI 发布变成通过。

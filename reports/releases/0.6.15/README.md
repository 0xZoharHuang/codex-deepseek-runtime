# CDS v0.6.15 安装器验收

本版本为安装器更新。原生 Codex runtime、模型路由及工具实现沿用固定的已发布组件。平台清单逐项核对了原生 recipe、补丁、归档 URL、SHA-256 和全部文件。[组件来源](native-inputs.json)

| 平台 | 原生组件基线 | 本版正常安装与工具验收 |
| --- | --- | --- |
| Windows x86_64 | v0.6.14，P39 | 待实际候选安装回执 |
| Linux x86_64 GNU | v0.6.13，归档来自 v0.6.10 | 待 hosted 原生安装回执 |
| macOS Apple Silicon | v0.6.13，P35 | 待 hosted 原生安装回执 |

Windows 的本地 HTTP 故障注入使用真实截断响应、续传响应和忽略 Range 的服务器。首次公开资产 Range 读取遇到连接重置，后续 206 响应的 64 字节与正式归档相同。该采样与完整安装分别验收。

可回滚到 Windows v0.6.14 或 Linux、macOS v0.6.13。每个平台的历史模型、沙箱和冷恢复验收记录保留在对应版本报告。

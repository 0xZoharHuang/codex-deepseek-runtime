# CDS 0.7.6 协议维护候选

本候选基于 0.7.5，保留既有 P35/P41 原生归档和运行时机制。对于经验证的非 `interrupted` 错误型 `response.incomplete`，字面 `model: unknown` 是未知身份，保留事件的原模型字段、原因、ID、usage 和不完整输出；不把未知身份当成路由证明或完成，不合成工具执行。显式不同模型或提供方、正常 completed、初始事件以及原生会继续执行的 interrupted 仍按原规则拒绝冲突。

身份校验拒绝时，本地 receipt 仅额外记录有限白名单事件阶段和终态；不在新增上下文中写入请求、ID、模型值或凭据。原失败消息、HTTP 状态、路由和重试机制不变。

独立 CADSG 的实际主任务中曾观察到 `model: unknown` 导致适配错误，原事件类型没有保存，generation 查询返回 404。因此此次窄修不能被宣称已经解决该次真实错误；受限阶段诊断用于后续定位。任何平台是否发布、正常安装和验证范围以对应 Release 证据为准。已运行任务不热更新。

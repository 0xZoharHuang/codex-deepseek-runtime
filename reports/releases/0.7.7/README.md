# CDS 0.7.7 原生 HTTP 启动维护候选

Windows 定向测试中，进程堆栈在原生 HTTP 辅助进程启动后的同步元数据写入处停留；单项测试最终约 15 秒通过。另一次分阶段测量的 fsync 为 0.13 秒，说明延迟存在波动；现有证据没有识别 Part Two WSL 生命周期检查超时的具体停点。

候选将原有持久写入放到工作线程，同一路径进程内串行，不同路径不互相等待；取消和关闭都要等待已发起写入结束，再退役辅助进程。保留原子替换、持久化和原生进程所有权，不改变网络超时或重新执行模型请求。

隔离本地合成反例在旧实现复现事件循环饥饿；候选通过同一路径并发、不同路径并行、重复取消、关闭顺序、持久化失败、实际原生 HTTP helper 和代理相关回归。具体平台 CI、正常安装和真实任务须独立验收；不得将本修复说成已证实解决 Part Two 的历史超时。

# CDS 0.7.9 Windows 安装权限维护候选

Windows 日常安装根目录包含安装器为原生受限令牌添加的非继承遍历授权；其他已设置的安全元数据授权也可能存在。旧安装器在升级开始时重置根目录 DACL，随后只重新添加自身的基础遍历权限，因此可能丢失其他授权并在中途短暂移除遍历权限。该现象在独立 Windows 目录复现；日常安装目录未用于试错。

候选对当前用户拥有的受保护安装根目录，验证专用用户与 SYSTEM 的完整继承权限以及其他非继承、仅遍历／读取属性／同步的授权，并保留已识别的原 ACL；对已有受管理安装中不符合约束的 ACL 明确拒绝。其他目录和平台继续执行既有隐私策略。此修复不修改原生沙箱实现、业务循环或 Defender 设置。

普通用户令牌的定向和安装回归、需要管理员权限的独立回归，以及隔离目录首次安装与保留额外授权后的再次安装证据分别记录；各平台最终安装、真实模型任务与发布状态仍以对应 Release 附件为准。CADSG 冷历史选择和 Part Two 的 40 秒超时不能由本修复推定解决。
